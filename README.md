# TVHelper · TradingView 助手

<img src="assets/icon.png" width="88" alt="TVHelper icon" />

一台电脑同时挂几个 TradingView 账号：每个账号一份独立配置、各自登录，同时在线不串号。
所有改动只发生在助手自己的副本里，系统里装的 TradingView 原封不动。

## 下载

到 [Releases](https://github.com/n0bele/TradingViewHelp/releases/latest) 下 `tvhelper-v*-windows-x64.exe`，双击就能用。

- Windows 10 / 11 64 位，免安装，不用另装运行库
- 程序没有代码签名，杀软报毒请加白名单（这类小工具常被误报）
- 只在本机跑，不上传账号信息

## 三步开始

1. 先装好官方 TradingView 桌面版，再打开助手 —— 顶栏会显示检测到的版本
2. 在「账号」里填个名字（比如「主号」）→ 点「添加」。第一次会自动生成免弹窗副本，约 1 分钟
3. 点账号卡片上的「启动」，在弹出的窗口里登录

之后都从助手启动。登录状态存在各自目录里，重启不用重登；要双开就再加一个账号。

## 功能

七个开关，拨了就生效（已经在跑的窗口要重启一次）：

| 开关 | 做什么 |
|---|---|
| 拦截广告弹窗 | 广告域名直接拦掉，订阅 / 升级窗口不再弹，图表里的推广浮层就地隐藏 |
| 多图表布局解锁 | 免费档只给 1 个图表，这里放开 |
| 指标叠加解锁 | 免费档子指标只能叠 1 个，这里放开 |
| 绘图不限 | 取消免费档单张图 30 个绘图的上限（隐藏 / 锁定的也占额度，删掉就释放），超额画的照常保存 |
| 断线自动恢复 | 弹「连接已关闭」时自动点恢复，4 秒不行就重载页面，再按 15 秒 / 1 分 / 5 分重试 |
| 禁用自动更新 | 去掉启动时的更新检查，手动检查照旧 |
| 本地指标报警 | 用图表上的任意指标建报警，条数不限，不占服务端配额，发系统通知或自己的邮箱 |

报警入口：图表工具栏「警报」下方的蓝色铃铛、右下角「报警 N」，或快捷键 `Alt+A`。助手关掉时没人监控；行情延迟多少，报警就跟着晚多少。

## 出问题先看这里

先看顶栏那个标签：

| 标签 | 意思 | 怎么办 |
|---|---|---|
| `● 副本 3.5.x · 补丁完好`（绿） | 一切就绪 | 功能还是没反应，看下面第 3 条 |
| `● 副本 3.5.x · 旧包未清除`（红） | 副本里还压着原始安装包，客户端会优先加载它，补丁一条都不执行 | 点「全部停止」，拨动任意一个开关（会自动清掉），再「全部启动」 |
| `● 副本 3.5.x · 补丁异常`（黄） | 有补丁没对上 | 拨一下任意开关重打；还不行就「全部停止」后删掉 `%USERPROFILE%\.tvx` 重来（账号要重新登录） |
| `● 副本未生成` | 还没建副本 | 「添加」一个账号，会自动生成 |

还没好，按顺序排查：

1. **客户端没关就重建** —— 文件被占用，构建会中止。先「全部停止」。
2. **杀软拦了文件操作** —— 典型表现是重建时删不掉旧包。把 `%USERPROFILE%\.tvx` 加进白名单。
3. **启动的不是副本** —— 快捷方式、任务栏、开始菜单如果指向系统里装的那份，补丁自然不生效。从助手启动，或去任务管理器看 `TradingView.exe` 的路径是不是 `.tvx\apps\...`。
4. **改完没重启客户端** —— 补丁在启动时加载，改完开关要重启窗口。

报警按钮不出现时，图表右侧有个红色「报警不可用」，鼠标停上去写着原因和处理办法。

顶栏出现红字「环境异常」时，旁边有「自检」按钮，会生成完整报告并写到 `%USERPROFILE%\.tvx\doctor.txt`。反馈问题把这份报告发来最省事。
