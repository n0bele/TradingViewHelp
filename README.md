# TVHelper · TradingView 助手

<img src="assets/icon.png" width="88" alt="TVHelper icon" />

## 功能

本地运行的 TradingView 桌面版多账号管理器：每个账号一份独立配置目录，多个账号可同时在线、互不串号；补丁只作用于本地副本，不改动已安装的 TradingView。

界面上的功能开关（拨动即自动重打补丁）：

- 拦截广告/追踪网络
- 多图表布局解锁
- 指标叠加解锁
- 绘图不限（单张图表 30 个绘图的上限）
- 屏蔽充值窗口
- 断线自动恢复
- 禁用自动更新
- 本地指标报警

## 本地指标报警

免费版只有价格报警。这条功能在本地补上**无限的本地指标报警**——用图上任意指标建报警，条数不限，不占服务端配额。

- 入口：绘图工具栏原生「警报」按钮下方的蓝色铃铛、右下角「报警 N」、或快捷键 `Alt+A`。
- 条件取自当前图表上那个指标实例自己声明的条件名（与原生对话框一致，如 `AST Trend Shift`），读不到时退回它的输出列与图形信号。
- 列表与原生警报面板同一套样式：一行一条，点开看详情与操作。
- 消息标题/内容可改，支持 `{{ticker}}` `{{close}}` 等占位符；通知可选系统通知与自填 SMTP 邮件（465 SSL 或 587 STARTTLS，账号 + 授权码）。
- 设置存本机账号目录（`tvx-alerts.json`），重启后自动恢复；**图表没开、品种或周期不符、指标被删时只显示「未就绪」，不会硬触发**。
- 边界：软件关闭就不监控；行情延迟随账号数据权限（免费版部分市场延迟 15 分钟）；服务端真正的报警（邮件/短信/webhook、关机也运行）仍然只有订阅才有。

## 绘图不限

免费版每张图表最多 30 个绘图（趋势线、水平位、斐波那契、矩形……都算），超了就「点了没反应 + 弹升级框」。这条开关把客户端那道检查去掉。

- **计数怎么算**：按单张图表（一个 layout）算，所有 pane 合计；同一种工具画 10 次就是 10 个。隐藏、锁定的绘图**照样占额**，删除立即释放。指标、脚本、报警不计入。
- **改的是哪一层**：上限检查在客户端（图表页 bundle 里的 `ensureDrawingsLimitAllowed`，见 `src/patch.rs` 的补丁注释），注入后该函数拿到空上限就直接放行；手绘、复制粘贴、克隆绘图、图片拖入走的是同一个入口。
- **已验证到哪一步**（登录态免费账号实测）：同一张图表连续建到 40 条不弹升级框；超额部分会正常提交服务端（布局保存请求 200，请求体里带 39 条趋势线），整页重载后 39 条原样回来。也就是说服务端没有第二道 30 的闸门，画得出来就存得住。
- 升级到付费方案后这个开关没有副作用，可以一直开着。

## 充值弹窗拦截

「屏蔽充值窗口」管三层，缺一层就会漏：

- **壳层**：订阅遮罩窗口不再创建、`showPaywall` 变空操作、网页请求开窗时按 URL 过滤充值/推广链接（含 `/desktop/paywall/`、`/pro-plans/features/`）。
- **图表页浮层**：`MutationObserver` 在节点插入 DOM 的那一刻判定并 `display:none`，不等它画出来，也不依赖某种语言的标题文案。
- **启动时序**：`dom-ready` 可能早于内部浏览器视图就绪，注入回调会等它就绪再执行（每 250ms 试一次，最多 5 分钟），不再出现"启动后近一分钟一条注入都没有"。

断线提示不走这一层：那是「断线自动恢复」的事，两边按文案区分——真断线框的标题是「关闭了这个连接」，不当推广藏掉。

实测（登录态免费账号，独立副本实例 + CDP，2026-11-25）：

- 同一份构造 DOM 做新旧脚本对照：**旧脚本会把「获取更多连接，同时查看更多图表」这张连接数付费墙原样显示**（它的标题以前被算作断线文案，直接放行），新脚本隐藏它；
- 真断线框（「我们关闭了这个连接」+「恢复连接」）仍然不隐藏，交给断线自愈点按钮（实测按钮被点 1 次）；
- 连接数付费墙不再被断线自愈当成断线（以前找不到「恢复连接」就重载页面，最多 4 次）；
- 逐条日志对照：`[tvx] dom-ready: browser view not ready, retrying` 只在视图确实未就绪时出现。

**不管的**：顶栏常驻的窄条推广按钮（`desktopUpgrade-*`）和全应用共用的 toast / 对话框通道——前者只能按尺寸猜、误伤面大，后者是全应用共用、按 URL 过滤不到。

## 构建

需要 Rust stable。

```bash
cargo build --release
# 产物：target/release/tvhelper(.exe)，Windows 另需 MSVC 工具链
```
